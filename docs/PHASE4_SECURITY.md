# Phase 4 security boundaries

Heartbeat is observation/reconciliation/preparation infrastructure. It does not grant itself authority. External communication, spending, employment/legal/medical commitments and other consequential actions continue through Phase 3 action policy. Delegation records are inert unless explicitly granted by Tylor and consumed by an approved executor. Source payloads are not copied wholesale into Black Box; provenance IDs, hashes, status and bounded metadata are preferred. Source freshness is truthful: a heartbeat check cannot make an old reading new.
