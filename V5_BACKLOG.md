# JARVIS V5 Backlog

This file intentionally captures ideas discovered during V4 without expanding the V4 acceptance scope.

## Rule
V4 ships when its defined operating loop is reliable. New ideas that are valuable but not required for V4 acceptance go here instead of destabilizing the field test.

## Candidates
- Voice Recorder sensor: ingest `Voice Recorder.zip` implementation once accessible; transcribe/capture context, commitments and latent intentions while preserving personal-message OBSERVE_ONLY boundaries.
- Stronger multimodal ambient context: voice/environmental signals become evidence, never implicit authority.
- Long-horizon intention warming: resurface dormant ideas only when location, time, energy, weather and goals make them unusually actionable.
- Recommendation calibration: per-domain confidence, interruption thresholds and decay rather than permanent preference changes from a single click.
- Explainability explorer: richer Black Box reconstruction, comparisons between recommendations, and explicit rollback of learned ranking changes.
- Cross-sensor contradiction handling: identify conflicts among calendar, messages, email, voice and user corrections and ask only when the conflict matters.
- Relationship-aware planning without autonomous personal messaging.
- More capable local/on-device reflex model after V4 behavior is proven.

## Promotion criteria
A candidate moves into V5 implementation only after V4 acceptance or when it fixes a V4 blocker rather than adding scope.
